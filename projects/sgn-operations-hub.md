# SGN Operations Hub

## Overview

SGN Operations Hub is a business workflow application focused on operational order processing, stock management, validation and document generation.

## Technology

- React
- TypeScript
- Vite
- SheetJS

## Key Areas

- Order file upload
- Excel processing
- Order processing
- Validation rules
- Processing workflows
- Stock reporting
- Order details
- Drug requirement workflows
- Label Excel generation
- PDF label generation
- Docket/posting workflow
- Role-based operations

## Technical Focus

The application focuses on converting operational processes into structured digital workflows with validation, processing and reporting capabilities.

## Project Status

The actual application is maintained as a private/local project.
