# AI Project Tracker

## Overview

AI Project Tracker is a project and team productivity tracking platform designed to analyze development activity, ticket timelines and project work.

## Technology

- React
- TypeScript
- GitHub API
- GitHub GraphQL
- AI

## Key Capabilities

- GitHub project analysis
- Issue tracking
- Ticket timeline analysis
- State transition tracking
- Employee work tracking
- Project productivity reporting
- Daily management reporting
- Monthly performance analysis
- Yearly performance analysis
- Non-ticket work tracking
- Carry-forward work
- Handover and partial completion tracking
- AI-assisted insights

## Technical Focus

The system uses GitHub data to build a structured view of project activity and development work.

GitHub GraphQL is used to obtain detailed timeline and state-transition information for tickets and project activities.

## AI Direction

The project explores how AI can assist with:

- Productivity analysis
- Management reporting
- Work summarization
- Performance insights
- Business decision support

## Project Status

The project is under active development and experimentation.
